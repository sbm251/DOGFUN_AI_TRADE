**PowerTrader AI – Community Edition (DOGFUN_AI_TRADE)**

PowerTrader AI is an open-source, AI-powered cryptocurrency trading bot that uses neural networks to analyze market data and automatically execute trades on Binance.

This project was originally created by Stephen Bryant Hughes, whose work, architecture, and core trading logic are the foundation of PowerTrader AI. Full credit and respect go to Stephen for creating and open-sourcing this project. None of the original functionality would exist without his work.

This version includes community-driven modifications and enhancements made by me. These changes are independent of the original author, and responsibility for them lies solely with the current maintainer.

----------------------------------------------------------------
**Updates & Enhancements**

Added a Trade Start Level setting, allowing users to choose how many blue (LONG) levels price must move below before a trade starts (previously fixed at 3).

Integrated Telegram with authentication, enabling secure remote monitoring, notifications, and selected controls.

Connected securely to Binance via API for automated trading (trading-only permissions, withdrawals disabled for safety).

Improved configurability and testing flexibility while preserving the original system design.
